KAPLAN KÜMESİ WEB UYGULAMASI

Bu paket iPad ana ekranına eklenebilen web uygulaması sürümüdür.

Kullanmak için:
1. Bu klasördeki dosyaları bir web sitesine yükle.
2. iPad'de Safari ile siteyi aç.
3. Safari Paylaş menüsünden 'Ana Ekrana Ekle' seç.
4. Ana ekrandaki Kaplan Kümesi simgesinden oyunu aç.

Not: PWA özelliklerinin çalışması için oyun internet üzerinde HTTPS ile yayınlanmalıdır.
